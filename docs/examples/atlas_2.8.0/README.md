# Przykłady syntetyczne 2.8.0

Wszystkie geometrie, zdjęcie oraz ilustracje w tym folderze są danymi kontrolnymi. Nie przedstawiają projektu użytkownika ani rzeczywistej dokumentacji terenowej.

- `scena_3d_NMPT.html`: samodzielny model Three.js z dwiema pozycjami obserwacji, budynkami i lasem; otwórz lokalnie po pobraniu.
- `model_z_oczu.png`: obraz z tego modelu, z dachu i terenu pokrytych syntetyczną teksturą.
- `fotomontaz.html`: własny plik obrazu jako tło i rzutowanie turbin; tło zostało narysowane do testów.
- `formularz_model.png`, `formularz_zdjecie.png`: układ podstawowych kontrolek QGIS; parametry dodatkowe otwierają się osobno.
- `profil_NMPT.svg`, `scena_3d_lekka_NMPT.html`: dodatkowe pliki powiązane ze sceną.

HTML zawiera skrypty i obrazy, bez pobierania bibliotek z CDN. Biblioteka Three.js ma licencję MIT osadzoną w pliku modelu. Rzeczywisty fotomontaż wymaga własnego kadru i prawidłowego ustawienia aparatu.
