# Przykłady 2.1.0 — dane syntetyczne

Żadna z tych map nie przedstawia inwestycji użytkownika. Są to sztuczne modele demonstracyjne, niezależne od załączników i ich geometrii.

`wysokosci_i_promienie_NMPT.png` to rzeczywiście wyrenderowane nowe warstwy w PyQGIS. `profil_NMPT.svg` i PNG to rzeczywisty wynik generatora profilu. HTML sceny zawiera tę samą syntetyczną siatkę, którą eksportuje wtyczka. Profile/sceny obu modeli pokazują różne zasięgi.

Aby otworzyć scenę, pobierz plik HTML i otwórz go lokalnie w przeglądarce. Do działania obrotu nie wymaga innych plików ani internetu. Link do profilu zadziała, jeśli obok HTML znajduje się odpowiedni `profil_NMPT.svg` lub `profil_NMT.svg`.

Na scenie widoczna jest tylko wybrana turbina. Linie widzenia odnoszą się do obserwatora na brzegu koła, nie do zmienianej myszą pozycji kamery. Skala kolorów opisuje metry wysokości. Siatka podglądu jest rzadsza od modelu analizy.
