# Syntetyczny przykład 2.5.0

HTML zawiera własną syntetyczną teksturę pól, 16 szczegółowych obrazów, modele NMT/NMPT, 136 ilustracyjnych koron i 3 budynki. Dane użytkownika nie są publikowane. Oba PNG są rzeczywistymi zrzutami obszaru WebGL z Chromium/SwiftShader. Po otwarciu HTML domyślnie działa kamera z oczu i prezentacja koron zamiast powierzchni lasu. Zdjęcie z góry pokazuje dopasowanie tekstury. Do sterowania wystarcza sam HTML; przekrój jest osobnym SVG. Materiał nie jest rzeczywistą ortofotomapą ani modelem realnej lokalizacji.
