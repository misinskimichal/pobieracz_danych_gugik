# Syntetyczny przykład 2.6.0

Dwa punkty w jednym samodzielnym HTML: droga z otwartym widokiem oraz skraj lasu. Modele wysokości, obrysy, tekstura pól i roślinność są syntetyczne; dane użytkownika nie są publikowane. Dachy dopasowano do zaprojektowanych próbek NMPT. Elewacje i listowie są materiałami poglądowymi. PNG są rzeczywistymi zrzutami WebGL w Chromium/SwiftShader. HTML ma listę miejsc i osadzone obrazy; nie wymaga serwera ani CDN. Profil SVG pozostaje pierwotnym przekrojem i nie przelicza się podczas zmiany kamery.
