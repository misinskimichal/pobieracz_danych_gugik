# Syntetyczny przykład 2.4.0

Własne, w całości syntetyczne modele gruntu, budynków, lasu i tekstura pól. Nie zawiera danych ani geometrii użytkownika. HTML jest samodzielny z osadzonym obrazem. Otwórz go lokalnie w przeglądarce z WebGL. Włączono widok z oczu; przycisk NMT + obiekty BDOT pokazuje uproszczone bryły bez ciągłej powierzchni NMPT. PNG jest rzeczywistym renderem geometrii i shaderów przez Mesa/EGL, nie zrzutem przeglądarki. Korony są próbkami, budynki mają płaskie dachy i neutralne ściany.
