# Przykład 2.2.0 — dane syntetyczne

Scena to rzeczywisty wynik generatora wtyczki na sztucznym terenie, lesie i zabudowie. Nie przedstawia inwestycji użytkownika. Nie zawiera załączonego PDF ani geometrii użytkownika.

Pobierz `scena_3d_NMPT.html` i otwórz lokalnie w przeglądarce. Siatka ma 434×434 punkty, krok 3 m przy analizie co 1 m, a scena promień 650 m (analiza 1000 m). Tekstura z syntetycznych warstw projektu jest osadzona w HTML. Są 67 uproszczonych symboli drzew z wysokością NMPT−NMT. Model podglądu jest powierzchnią 2,5D.

`scena_3d_lekka_NMPT.html` działa bez WebGL. Aby używać odnośników między sceną i profilem, zachowaj pliki w jednym folderze. Domyślna kamera patrzy od strony obserwatora przekroju; jej obrót pokazuje model z innych stron. Kolory wysokości i kolory pokrycia mają inne znaczenie.
